# Portafolio Unidad 1 - Ensayo de Compresión

## Propósito
Este proyecto corrige, organiza y documenta los datos de un ensayo heredado, mejorando su trazabilidad y reproducibilidad.

## Entradas
* Datos crudos del ensayo (cargas y desplazamientos).
* Dimensiones de la probeta: Diámetro = 150 mm Altura = 300 mm.

## Procedimiento
1. Se genero una copia los datos originales para no sobreescribirlos.
2. Se calculó el área transversal de la probeta utilizando el diámetro.
3. Se verificaron y documentaron las unidades correctas: Desplazamiento (mm), Carga (kN) y Esfuerzo (MPa).

## Salidas
* Planilla de cálculo corregida con unidades estandarizadas.
* Gráfico de esfuerzo vs desplazamiento.
* Informe final actualizado.

## Herramientas utilizadas
* Microsoft Excel / Word
* Asistente de IA (Gemini 3.1 Pro) para revisión de estructura y redaccion.
